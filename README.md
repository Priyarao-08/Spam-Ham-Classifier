# Spam/Ham Classifier

## Description
A Machine Learning and Streamlit-based application that classifies SMS or text messages as Spam or Ham.

## Features
- Single Message Classification
- Bulk CSV/Excel Message Classification
- User-friendly Streamlit Interface

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run st_3.py
